# Live Score App

Sistem Manajemen Lomba dan Live Score.

## Fitur Utama
- **Live Leaderboard**: Skor diperbarui secara real-time.
- **Manajemen Grup & Instansi**: Mengelompokkan peserta berdasarkan grup.
- **Sistem Poin Dinamis (Biasa & Bidding)**: Pengaturan nilai poin yang bisa diubah secara fleksibel dan instan.
- **Rekap Hasil**: Ekspor hasil juara ke dalam bentuk PDF.

## Stack Teknologi
- **Next.js**
- **tRPC**
- **Prisma**
- **Tailwind CSS**
